> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Tool → CSPS_Legacy_Restore | The session is sysadmin on LocalDB; the engine does not enforce read-only | Real customer and staff data (read only) |
| Tool → SQL Server (trial) | The tool creates, migrates and drops a throwaway database | Copied customer data, pseudonymous staff |
| Tool → shared LocalDB | TheBETSLLC's databases share the instance | None (refused before connect) |
| Legacy values → domain | Legacy text and money are untrusted input | Order and expense values |
| Tool → file system (`_local`) | Output lands next to tracked files | Full findings with values |
| Summary / docs → public repo | Committed text cannot be recalled | Counts, rule keys, list words only |
| Tool console → AI transcript | Console output leaves the machine | Counts and relative paths only |
| Repo → deploy package | Anything the Server references ships to the host | None (tool excluded) |
| Owner answers → planning docs | Later agents act on recorded rulings | Dated rulings |
