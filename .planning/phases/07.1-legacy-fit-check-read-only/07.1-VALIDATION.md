# Phase 07.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Source: `07.1-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | xunit.v3 4.0.1 on Microsoft.Testing.Platform, Shouldly 4.3.0, NSubstitute 6.2.0 |
| **Config file** | `tests/Directory.Build.props` (projects ending in `Tests` become MTP test exes) |
| **Quick run command** | `dotnet test --project tests/Csps.LegacyFitCheck.Tests --filter-class "*<ClassName>"` (a filter that matches nothing exits 8) |
| **Full suite command** | `dotnet build Csps.slnx -tl:off`, then `dotnet test --project` per test project as in `.github/workflows/ci.yml`, then `powershell -NoProfile -ExecutionPolicy Bypass -File tools/scripts/Invoke-CoverageGate.ps1` |
| **DB-backed tests** | Run the preflight first. Local runs use LocalDB (`CSPS_TEST_SQL` unset); CI uses `CSPS_TEST_SQL=container` |
| **Estimated runtime** | ~60 to 180 seconds per project with DB tests |

---

## Sampling Rate

- **After every task commit:** the task's `--filter-class` run, plus `dotnet build Csps.slnx -tl:off` with zero warnings
- **After every plan wave:** all of `tests/Csps.LegacyFitCheck.Tests` and `tests/Csps.ArchitectureTests`; if Domain changed, `tests/Csps.Domain.UnitTests` plus the coverage gate
- **Before `/gsd-verify-work`:** full CI-equivalent suite green and `dotnet format Csps.slnx --verify-no-changes`
- **Max feedback latency:** 180 seconds
