# Phase 13: UI Design Contract (Quote Inquiries)

*Created: 2026-11-21T21:30:00-06:00 · Updated: 2026-11-21T21:30:00-06:00*

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Owner conventions apply to everything below** (`.claude/CLAUDE.md` Conventions): admin parts import from `@/components`; public parts import from each component's own module file, never an area barrel (PERF-01); module code lives in `web/src/modules/public/` and `web/src/modules/admin/` (`pages/`, `components/`, `hooks/`, `services/`, plus module-root copy and schema files, OR-6); no em dash or en dash in any client string, `aria-label`, `title`, `<title>`, email text or comment (OR-4); a missing value renders `EmptyValue`, never a dash; every form has a zod schema that mirrors its API validator with the server's own messages, shown inline before anything is sent (OR-3); API calls live in per-module services and only `core/api/http` touches `fetch` (OR-5); no `style` attribute or inline script anywhere (strict CSP). **Every count, status, date and photo state comes from the server.** The client formats only.
