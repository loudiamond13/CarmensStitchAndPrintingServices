<objective>
The phase tracer on the server (RESEARCH Pattern 1, Pattern 2): replace `MapFallbackToFile` with one shaped shell endpoint that fills a marked block in the built `index.html` with the page's own head, sets the real status (200 known page, 404 unknown, `noindex` on `/admin*`), and add `robots.txt` and `sitemap.xml`. Phase goal (ROADMAP, verbatim): "Visitors arriving on a phone from Facebook can browse Home, Products, Gallery and Contact, with real business info and prices from the database, and their link previews look right. Managers keep all that content current without a developer."

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-11-03 | Spoofing | canonical, og:url, robots.txt, sitemap.xml (CWE-644) | high | mitigate | Origin from AppLinksOptions.PublicBaseUrl only; ShellPageTests and SeoEndpointTests send a forged Host and assert the configured origin. |

| T-11-SC | Tampering | npm and NuGet installs | high | mitigate | No package added or bumped. |
