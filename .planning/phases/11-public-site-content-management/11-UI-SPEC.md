# Phase 11: UI Design Contract (Public Site and Content Management)

*Created: 2026-11-11T08:41:00-06:00 · Updated: 2026-11-11T09:20:00-06:00*

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Owner conventions apply to everything below** (`.claude/CLAUDE.md` Conventions): components from `@/components` (admin) or from their own module files (public, PERF-01: the public layout never imports an area barrel); module code in `web/src/modules/public/` and `web/src/modules/admin/` (`pages/`, `components/`, `hooks/`, `services/`, module-wide copy and schema files); no em dash or en dash in any client string, `aria-label`, `title`, `alt`, `<title>` or meta text (OR-4); a missing value renders `EmptyValue`, never a dash; every form has a zod schema that mirrors its API validator and shows inline errors before any request is sent (OR-3); API calls live in per-module services and only `core/api/http` touches `fetch` (OR-5); the owner layout tree (OR-6); no `style` attribute or inline script anywhere, including the server-shaped HTML (strict CSP). **Every price, count, open or closed status and piece total comes from the server.** The client formats only, and the labelled "Visitors see" previews inside admin forms are the only client-built text.

**What this file is.** The phase-scoped contract for the four real public pages (Home, Products, Gallery with its lightbox, Contact), the 404 page, the server-sent page head (titles, descriptions, Open Graph, `LocalBusiness` JSON-LD, `noindex`), the footer and sticky bar bound to site settings, the Manager-only **Site Content** admin area (Business Info, Hours & Closures, Products with the product line editor, Testimonials, Gallery), and the **Public website** card and window on the order screens (both roles). It creates **no new design token, color, font, font size or weight**. `CSPS-UI-SPEC.md` ("the spec") stays the visual source of truth with its precedence (Appendix, then tables, then prose); §7 and App. E.1 to E.4 are the look of every public page. `02-UI-SPEC.md` ("P2") stays binding for the Tailwind contract, recipes, the inline style rule, the look-equality proof and the interaction contract; `05-UI-SPEC.md` ("P5") for the shell, row actions (05 D-51) and motion; `06-UI-SPEC.md` ("P6") for the Settings card pattern (S1); `08-UI-SPEC.md` ("P8") for the order page, windows, save bar and dirty guard (08 D-57, D-58); `09-UI-SPEC.md` ("P9") for photo picking, `prepareImage`, upload states and the viewer frame; `10-UI-SPEC.md` ("P10") for structure. This file only adds what Phase 11 needs.

| New packages | **none.** |

Jersey SVG colors are SVG `fill` attributes, not styles (spec §13: "No hex colors appear in TSX except the jersey illustration data").
