## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub runner → SmarterASP.NET Web Deploy (port 8172) | Credentials and the package cross the internet |
| workflow inputs → deploy script | The owner's dispatch inputs choose what is deployed |
| CI artifact / release → live site | Stored packages become the running site |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-25 | Information Disclosure | Web Deploy password in logs (CWE-532) | high | mitigate | Every printed command goes through redact(); tests assert the password never appears; GitHub masks secrets as a second layer |
| T-03-26 | Spoofing | Unverified Web Deploy TLS (CWE-295) | high | mitigate | -allowUntrusted only after a SHA-256 leaf-certificate pin match from WEBDEPLOY_CERT_SHA256; unset means verified TLS only |
| T-03-27 | Denial of Service | Site left broken or offline after a failed deploy | high | mitigate | Automatic rollback to the last good release, branded offline page on unrecoverable failure, `online` escape hatch, all tested |
| T-03-28 | Tampering | Deploying a build that never passed CI | high | mitigate | Package only from a successful push run on main for that sha, or an existing deploy release |
| T-03-29 | Tampering | msdeploy argument injection through inputs (CWE-88) | medium | mitigate | sha must match `^[0-9a-f]{40}$`; credentials with separator characters refused; arguments built by one pure function, no shell |
| T-03-30 | Information Disclosure | Probe key leaked or probe left reachable | medium | mitigate | Key from a secret, never logged, written only into the runner's temp publish folder; the probe answers 401 without it; the next CSPS deploy deletes its files |
| T-03-31 | Tampering | Sync deleting the host's logs | medium | mitigate | `-skip` rule for the logs folder, asserted in tests |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs; Node built-ins and the runner's msdeploy, gh and tar |
</threat_model>
