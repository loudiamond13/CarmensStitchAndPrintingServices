## Phase Goal

ROADMAP goal for Phase 3 (verbatim): "Every pull request is gated by the full pipeline. Every merge to `main` deploys to a SmarterASP.NET staging site that passes a smoke test, and production deploys wait for manual approval."

As amended by 03-CONTEXT.md (owner, 2026-10-15): the owner puts the Web Deploy credentials into GitHub (D-18 step 5); the first deploy has no rollback target, so the host is proven read-only first and its facts are read before CSPS goes live (D-06, research Pitfall 5).
