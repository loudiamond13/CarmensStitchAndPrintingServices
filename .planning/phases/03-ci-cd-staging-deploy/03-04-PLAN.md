<objective>
Decide each CI run's mode in one tested place: `fast` for drafts, `docs` for documentation-only PRs, `full` for everything else, and `package` for a push to main whose exact tree already passed the full gate on its PR.

Purpose: D-14 saves minutes on drafts and docs; research Pattern 9 avoids paying the full gate twice per merge (the minutes table only fits under 2,000 with it). A wrong `docs` answer would skip real checks, so every rule fails toward `full`.
Output: `web/scripts/ci-classify.mjs` and its tests. Plan 03-11 wires it into ci.yml's classify job.
</objective>
