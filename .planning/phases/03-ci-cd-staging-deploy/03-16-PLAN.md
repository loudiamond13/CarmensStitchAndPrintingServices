## Phase Goal

ROADMAP goal for Phase 3 (verbatim): "Every pull request is gated by the full pipeline. Every merge to `main` deploys to a SmarterASP.NET staging site that passes a smoke test, and production deploys wait for manual approval."

As amended by 03-CONTEXT.md (owner, 2026-10-15): every ready PR runs the whole ordered pipeline (D-14), merged only through the process gate (D-08); the repo stays private and free (D-07, D-16).

## Executor Rules (every task)

- **Timestamps (owner rule):** every `.md` you create or edit carries ISO 8601 `created:`/`updated:` timestamps with the -05:00 offset.
- **Git and GitHub:** stay on `gsd/phase-03-ci-cd-staging-deploy`; never create, rename, switch or delete a branch; never merge (plan 03-17 does that on the owner's instruction); repository settings change only as the owner approved in Task 1; never change visibility, billing or the spending limit.
- **Fix-ups:** a Linux-only failure is fixed at its cause in the file that owns it (commit `fix(03-16): ...`), at most five rounds; list every file touched in the SUMMARY. No threshold is lowered and no retry added; a Lighthouse score that only flakes on the shared runner is returned to the owner as a decision (median of three runs needs owner approval, research Pitfall 10).
- **Packages:** none.
