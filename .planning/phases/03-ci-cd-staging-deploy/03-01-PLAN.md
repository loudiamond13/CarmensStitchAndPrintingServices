## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR content → GitHub runner | Branch names, PR titles and code from the PR reach the workflow |
| third-party action code → runner | Pinned action code runs with the job token |
| runner → repository | The job token can read (and, if granted, write) the repo |
