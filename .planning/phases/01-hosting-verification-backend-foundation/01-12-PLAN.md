Program maps only GET /probe: when HostProbe:Key is not configured (or too short) respond 503 with an empty body; when the X-Probe-Key header does not match respond 401 with an empty body; otherwise return `HostFacts.Collect(HttpContext, IHostEnvironment, TimeProvider)` as JSON with Cache-Control no-store. HostFacts fields: frameworkDescription, environmentVersion, is64BitProcess, processName, inProcess (processName equals w3wp), currentDirectory, contentRootPath, logsWritable (create, write and delete a temp file under {contentRoot}/logs), remoteIpAddress, xForwardedFor, xForwardedProto, xRealIp, cfConnectingIp, isHttps, manilaZone (TimeZoneInfo.TryFindSystemTimeZoneById("Asia/Manila") result and the zone id), enPhCulture (whether CultureInfo en-PH loads and how it formats 12450 as currency), ephemeralPfxRoundTrip (create an RSA-2048 self-signed certificate in memory, export a PFX with a random password, reload with X509CertificateLoader.LoadPkcs12 and EphemeralKeySet, RSA OAEP encrypt/decrypt a short string; report true/false and the exception type name only), totalAvailableMemoryBytes (GC.GetGCMemoryInfo), and checkedAtUtc (TimeProvider.System; banned clock APIs stay banned).
