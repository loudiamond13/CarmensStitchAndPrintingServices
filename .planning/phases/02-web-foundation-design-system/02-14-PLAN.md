## Executor Rules (every task)

- **Timestamps (owner rule):** every `.md` you create or edit carries ISO 8601 timestamps with offset; on an edit change only `updated`.
- **Packages:** none (lucide-react 1.53.0 is installed, D-34). Any install stops for a blocking-human `checkpoint:decision`.
- **Checkout:** if `web/node_modules` (or `tools/openapi-gen/node_modules`) is missing in this checkout, for example in a fresh worktree, run `npm --prefix web ci` (and `npm --prefix tools/openapi-gen ci`) first; it installs only what the committed lockfile pins and is not a package change. Parity, E2E, Lighthouse and review runs take run locks under `web/.locks/`; if one is held by another executor, wait and retry, never delete it.
- **Markers (D-07, ROADMAP criterion 2):** every change to App. D.3 behaviour, markup, props or copy that the strict gates or an owner ruling require is the smallest fix and carries `// SPEC-DEVIATION: <reason with decision ID>`; class-name changes alone are D-33 and need no marker; every SPEC-GAP file starts with `// SPEC-GAP: <primitive>`.
- **Look (D-08):** if making a component equal needs a change to the rendered look, the elements, the text or the ARIA structure beyond the UI-SPEC intentional-differences list, STOP and return a `checkpoint:decision` with a plain-words before/after for the owner. Reproduce cascade accidents; never "fix" them silently (Pitfall 29).
- **D-33 transcription:** copy spec values; never the "nearest" Tailwind value; no `[font:inherit]` (Pitfall 24); `[transform:…]` for transforms (Pitfall 25); `not-disabled:` never `enabled:` (Pitfall 27); always duration + easing on transitions (Pitfall 28); `cursor-pointer` where the spec's button shows a pointer (Pitfall 30); base/variant/size axes set disjoint properties.
- **Shared machine:** preflight before every parity run; never kill another project's process.
- **Reference (D-37):** `git show 74621f5:web/src/ui/icons.ts` (lucide map, aliases) may be read; its `csp-*` class strings never. Stay on `gsd/phase-2-web-foundation-design-system`. Zero warnings.
