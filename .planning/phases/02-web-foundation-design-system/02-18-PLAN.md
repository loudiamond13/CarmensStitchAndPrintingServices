## Executor Rules (every task)

- **Timestamps (owner rule):** every `.md` you create or edit carries ISO 8601 timestamps with offset; on an edit change only `updated`.
- **Packages:** none; any install stops for a blocking-human `checkpoint:decision`.
- **Checkout:** if `web/node_modules` (or `tools/openapi-gen/node_modules`) is missing in this checkout, for example in a fresh worktree, run `npm --prefix web ci` (and `npm --prefix tools/openapi-gen ci`) first; it installs only what the committed lockfile pins and is not a package change. Parity, E2E, Lighthouse and review runs take run locks under `web/.locks/`; if one is held by another executor, wait and retry, never delete it.
- **Markers (D-07, ROADMAP criterion 2):** every change to App. D.3 behaviour, markup, props or copy that the strict gates or an owner ruling require is the smallest fix and carries `// SPEC-DEVIATION: <reason with decision ID>`; class-name changes alone are D-33 and need no marker; every SPEC-GAP file starts with `// SPEC-GAP: <primitive>`.
- **Look (D-08):** any fix that changes the rendered look, elements, text or ARIA beyond the intentional-differences list → STOP with a `checkpoint:decision` and a plain-words before/after. Reproduce cascade accidents.
- **D-33:** complete `tw('…')` literals, disjoint axes, dynamic values only through `style={{ '--ratio': value }}`; multi-function transforms and clip-paths as arbitrary properties; gradients with the `image:` hint (docs/web/styling.md).
- **Shared machine:** preflight before every parity run.
- **Reference (D-37):** `git show 74621f5:web/src/ui/mark.tsx` (JSX mark) may be read for behaviour. Stay on `gsd/phase-2-web-foundation-design-system`. Zero warnings.
