## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → ASP.NET Core static files and SPA fallbacks | Untrusted paths and methods reach anonymous endpoints under a default-deny policy |
| test host → web root | Tests must never depend on build output that may hold anything |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Elevation of privilege | Anonymous SPA/static fallbacks under the fallback policy | high | mitigate | Only the five keys in this plan are AllowAnonymous; each has a matrix row and allow-list entry; DiscoveredEndpointsAreFullyCovered fails on any other anonymous endpoint (CWE-862) |
| T-02-02 | Information disclosure | Shell fallback swallowing `/api/*` | medium | mitigate | Literal `/api/{**path}` fallback outranks `{*path:nonfile}`; UnknownApiRouteIsStillProblem404 |
| T-02-03 | Information disclosure | `/openapi`, `/scalar` in production | medium | mitigate | Reserved-prefix 404 fallbacks outside Development (D-29); ReservedDocsPathsAre404OutsideDevelopment + ProductionHasNoApiDocs |
| T-02-04 | Spoofing | POST to page paths reaching the shell | low | mitigate | MapFallbackToFile is GET/HEAD only; UnservedMethodOnAPagePathIsChallenged asserts 401 |
| T-02-SC | Tampering | npm/NuGet installs | high | mitigate | No installs in this plan; any install stops for a blocking-human checkpoint:decision (owner package rule, D-25) |
</threat_model>
