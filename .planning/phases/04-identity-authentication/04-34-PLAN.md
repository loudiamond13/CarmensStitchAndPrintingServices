<objective>
Give the session store the operations that refresh rotation, sign-out, "sign out other devices" and password reset need, and tell handlers which session is the caller's own.

Purpose: AUTH-05 rotation needs the presented token with its session and siblings; AUTH-06 and D-05 need "revoke every other session of this user" with immediate effect through the cache; D-05 and D-43 need the caller's session id to keep "this device". Split from plan 04-13 so each plan stays inside the context budget; it runs beside plan 04-14, which needs none of it.
Output: `ISessions.{FindByRefreshHashAsync, AddToken, RevokeAllAsync}` with `RefreshLookup`, user-wide cache eviction, `IRequestContext.SessionId`, `SessionStoreTests` and the new `HttpRequestContextTests` cases.
</objective>
