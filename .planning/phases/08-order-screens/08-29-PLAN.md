Person B uses a second context from `browser.newContext` (same baseURL and HTTPS options as profile-email.spec.ts), closed in a `finally`. B deletes the 3,000.00 payment from the Payments tab. A types 8000, chooses Cash and presses Save Payment. The window reads the order, the check passes, and the save sends the opened version. The server answers 409 (allow it with `guard.expectStatus` on the payments path), and the window shows the banner with Load Latest. A presses Load Latest; the typed values stay. A saves again and sees the success toast and a balance of ₱1,360.00.
    2. Focus refresh (D-95). Use the same seed shape. A opens Add Payment, and B deletes the 3,000.00 payment. A's tab regains focus: dispatch a `visibilitychange` event on A's page the way TanStack's focus manager hears it. "Balance due: ₱9,360.00" shows without pressing Save.
    3. Mark Completed (D-96). The order is 9,360.00 with 9,000.00 paid, so the balance is 360.00. A opens the order page. B records a 360.00 payment. A opens Change Status, and Mark Completed is enabled with no reason line. A presses it and sees the order Completed.
