# Plan 08-08: Settings tabs for the order lists

*Created: 2026-10-29T16:00:00-05:00 · Updated: 2026-10-29T16:00:00-05:00*

<objective>
Turn Settings into four list tabs (D-31) so a Manager can add, rename, recolor (D-32), retire, use again and delete never-used product types, payment methods and order expense categories, with the company expense categories tab unchanged.

Purpose: the order windows pick from these lists; the Manager keeps them right.
Output: ListSettingsSection, a parameterized CategoryModal, useSettingsTab, list schemas and copy, tests and e2e.

Reversibility per CONTEXT D-31: reversible (no flag).

Phase goal (ROADMAP, verbatim): "Staff can run every order day to day in the portal. They can find an order, create one, work its detail page (items, payments, discounts, expenses, totals and estimated profit) and delete it safely."
</objective>
