# Plan 08-07: A Manager can read a deleted order

*Created: 2026-10-29T16:00:00-05:00 · Updated: 2026-10-29T16:00:00-05:00*

<objective>
Add the owner-approved Manager-only route `GET /api/v1/orders/deleted/{id}` (D-24) that answers a soft-deleted order with every child row, so Deleted Orders can show its counts before a permanent delete and open it read-only.

Purpose: ORD-06 screens (08-20, 08-23) need the whole deleted order. Reversibility per CONTEXT: costly (a new public route in the matrix and API docs).
Output: response record, handler, reader method, controller action, matrix row, tests, docs, regenerated contract.

Serial contract rule: this is the second and last plan that rewrites `openapi.v1.json` and `api.generated.ts`, in wave 2 after 08-01 (wave 1). No other plan touches those files.

Phase goal (ROADMAP, verbatim): "Staff can run every order day to day in the portal. They can find an order, create one, work its detail page (items, payments, discounts, expenses, totals and estimated profit) and delete it safely."
</objective>
