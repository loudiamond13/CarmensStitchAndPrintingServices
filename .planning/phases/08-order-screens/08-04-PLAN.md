# Plan 08-04: The three order lists in pickers

*Created: 2026-10-29T16:00:00-05:00 · Updated: 2026-10-29T16:00:00-05:00*

<objective>
Give the web the three Phase 7 order lists (product types, payment methods, order expense categories): one service and one query hook per list, and one `ListEntrySelect` that any form or filter uses, generalized from Phase 6's `ExpenseCategorySelect`.

Purpose: the list filter (08-09), the create form (08-13), the item, payment and expense windows and the Settings tabs (08-08) all read these lists the same way.
Output: three services with full call sets, three hooks, ListEntrySelect, list copy.

Phase goal (ROADMAP, verbatim): "Staff can run every order day to day in the portal. They can find an order, create one, work its detail page (items, payments, discounts, expenses, totals and estimated profit) and delete it safely."
</objective>
