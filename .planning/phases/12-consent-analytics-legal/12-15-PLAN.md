# Plan 12-15: Each page a visitor opens is counted once, with the address cut to the page and nothing more

*Created: 2026-11-15T23:30:00-06:00 · Updated: 2026-11-15T23:30:00-06:00*

> MVP note: the ROADMAP Goal line for Phase 12 is not in user-story form. No story was invented.

<objective>
TDD feature (RESEARCH Pattern 3 "Client side" and the "pending landing view" state machine): the public layout sends one page-view beacon per route change with the pathname only, holds the landing view while the bar asks, and flushes it exactly once.

Purpose: honest counts that respect the bar (nothing sent twice) and never leak search text (ANL-05).
Output: `keepalive` in httpClient, `analyticsService.pageView`, `usePageViewBeacon` with a pure machine, and the layout wiring.
</objective>
