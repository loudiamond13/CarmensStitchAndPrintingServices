# Phase 10: UI Design Contract (Admin Dashboard and Staff Money)

*Created: 2026-11-05T11:09:00-06:00 · Updated: 2026-11-09T09:50:00-06:00*

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Owner conventions apply to everything below** (`.claude/CLAUDE.md` Conventions): components from `@/components`; module code in `web/src/modules/admin/` (`pages/`, `components/`, `hooks/`, `services/`, module-wide copy and schema files); no em dash or en dash in any client string, `aria-label`, `title` or `alt` (OR-4); a missing value renders `EmptyValue`, never a dash; every form has a zod schema that mirrors its API validator and shows inline errors before any request is sent (OR-3); API calls live in per-module services and only `core/api/http` touches `fetch` (OR-5); the owner layout tree (OR-6). **Every figure on these screens comes from the server** (Core Value, MONEY-01). The client only formats figures, and the one preview it shows (the resulting balance in the delete dialog, D-33) is built from server balances fetched when the dialog opens.

**What this file is.** The phase-scoped contract for the dashboard at `/admin` (greeting, the personal money strip, four KPI cards, the income vs expenses chart with its profit line, Orders by status, Recent orders), the new My Money page at `/admin/money` (balance, ledger, the Manager's All Staff and Transfers tabs), one person's money page for Managers, the transfer and hand-over window, the delete and permanent-remove dialogs, and the sidebar item. It creates **no new design token, color, font, font size or weight**. `CSPS-UI-SPEC.md` ("the spec") stays the visual source of truth with its precedence (Appendix, then tables, then prose). `02-UI-SPEC.md` ("P2") stays binding for the Tailwind contract, recipes, the inline style rule and the interaction contract; `05-UI-SPEC.md` ("P5") for the shell, ActorName, row-action spacing (05 D-51) and motion (05 D-37 to D-39); `06-UI-SPEC.md` ("P6") for PaidBySelect and the list slice pattern; `08-UI-SPEC.md` ("P8") for DueFlag, the Delivered status, the order balance states and the window and dialog rules (08 D-57, D-58). This file only adds what Phase 10 needs.
