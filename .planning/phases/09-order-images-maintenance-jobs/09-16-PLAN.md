# Plan 09-16: Add photos on the order page

*Created: 2026-10-31T18:00:00-05:00 · Updated: 2026-10-31T11:52:00-05:00*

> MVP note: the ROADMAP Goal line for Phase 9 is not in user-story form. No story was invented.

<objective>
The web tracer: on an order's page staff pick photos (camera, gallery or drop), each is prepared in the browser, checked against the server's rules, queued in memory and uploaded one at a time with count-based progress; saved photos appear with server-sized thumbs; failures wait with Try Again and Remove; leaving with pending files asks first.

Purpose: ORD-04 "staff can upload images to an order ... later", IMG-05 (camera capture downscaled first), D-09 to D-10, D-17, D-18, D-29, D-31; Playwright stays away from Cloudinary through the Testing routes of plan 09-09 (D-07).
Output: service, rules query, upload queue, schemas, module copy, the O1 Images card, the page swap and the `@order-photos-upload` e2e journeys.

Revision note (2026-10-31, plan budget): the Testing image routes, their tests, matrix rows and docs moved to plan 09-09, so this plan is web only.

Phase goal (ROADMAP, verbatim): "Staff can attach, arrange and view order photos, including straight from a phone camera. The photos load fast and stay private per the OD-9 ruling. Storage cleanup and token purges run as short, reliable, scheduled jobs."
</objective>
