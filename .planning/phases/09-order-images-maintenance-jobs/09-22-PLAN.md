# Plan 09-22: The maintenance run happens every month, and on "Run now"

*Created: 2026-10-31T18:00:00-05:00 · Updated: 2026-10-31T11:52:00-05:00*

<objective>
A GitHub Actions workflow that calls the maintenance endpoint once a month and on demand, through a small tested Node script that loops while there is more work, writes plain counts to the run summary and turns the run red on any failure.

Purpose: JOB-01 "triggered on a schedule (GitHub Actions cron)" (01 D-10), D-21 (monthly plus Run now), D-22 (a red run emails the owner) and D-36 (counts only in the public summary).
Output: the workflow, the script and its tests, the CI rule update for the one maintenance secret, the workflow shape test and the runbooks.

Phase goal (ROADMAP, verbatim): "Staff can attach, arrange and view order photos, including straight from a phone camera. The photos load fast and stay private per the OD-9 ruling. Storage cleanup and token purges run as short, reliable, scheduled jobs."
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-54 | Information disclosure | key or bodies in public logs | high | mitigate | Key only in env, never printed; summary built from parsed labels and numbers only; fixed failure lines (D-36). |
| T-09-55 | Tampering | script injection through expressions | medium | mitigate | No ${{ }} in run lines (NoExpressionSinkInRun); env-only inputs; zizmor in Hygiene. |
| T-09-56 | Elevation | workflow token with write rights | medium | mitigate | permissions {} at both levels; checkout without persisted credentials. |
| T-09-57 | Denial of service | schedule silently stopping | medium | mitigate | Documented 60-day pause and Run now; a red run emails the owner (Pitfall 15). |
