## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser to page view route | Anonymous visitors send one page view per page load | The page path only, query and fragment cut off; no cookie, no visitor id |
| Browser storage | The saved Show Map choice stays in the visitor's browser | One `csps-maps` value; never sent to the server |
| Public site to Google | The Contact map frame loads from Google only after a tap or a saved tap | The embed request; Google may set its own cookies |
| Staff to Visitor Stats | Managers read and export the daily page tally | Daily counts per page; no personal data |
| Owner to published legal text | Only the owner can make the Privacy Policy final | The approval flag and date |
| Test build to Testing seed | The analytics seed exists only in Debug test hosts | Test rows in `CSPS_E2E` or `CSPS_Test_<guid>` only |
