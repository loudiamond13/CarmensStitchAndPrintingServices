# Plan 12.1-07: Browsers that still hold the old consent or visitor id cookie lose them on their next visit

*Created: 2026-11-18T18:00:00-06:00 · Updated: 2026-11-18T18:28:27-06:00*

> MVP note: the ROADMAP Goal line for Phase 12.1 is not in user-story form. No story was invented.
> Spec-less probe fallback skipped: the phase has no requirement IDs to probe (visible skip, recorded here). Traceability keys are the owner rulings (D-IDs).

<objective>
D-63: the server expires the old consent cookie and the old visitor id cookie when a browser still sends them (test browsers from Phase 12), so the site can truthfully say it sets no optional cookies. Design (Claude's discretion, CONTEXT): one small middleware after the static files, using `Response.OnStarting` and `Response.Cookies.Delete` with the exact set-time options (RESEARCH § D-63).

No ANL or LEGAL requirement is reduced here (ANL-04's server-side expiry of HttpOnly cookies lives on in this one-time cleanup).

Purpose: no leftover optional cookie survives in any browser that ever saw Phase 12.
Output: `RetiredCookiesMiddleware`, its registration, integration and e2e tests.
</objective>
