## Warnings

- **WR-G1-01** `src/Csps.Server/Security/RateLimitingRegistration.cs`: the D-74 site-wide ceiling is the `GlobalLimiter`, which takes its lease before the per-address limit refuses a call, so one address's refused calls use up the ceiling and every visitor's beacon gets 429 (views silently lost). Fix: chain the per-address limiter before the ceiling; test with two addresses.
- **WR-G2-01** `web/src/modules/public/legalPrivacy.ts:78, 114`: the draft Privacy Policy says the map loads "only after you tap Show Map"; since D-65 a returning browser loads it by itself, and the page's own saved settings section says so. Wording needs the owner (D-73).
- **WR-G3-01** `web/e2e/visitor-stats.spec.ts:162-181`: "Manager sees each count rise" reads pages from the top 5 list; in the shared, growing `CSPS_E2E` database a page outside the top 5 reads 0 and fails. Fix: assert on the Page views total.
- **WR-G3-02** `SeoEndpointTests.cs:79-88` (and 62, 114, 128), `ShellHeadTests.cs:927-940`: the sitemap test for `/cookies` uses a stub that never approves it, so it cannot fail, and other tests build their expected values from the code under test. Fix: approve `/cookies` in the stub and assert it is still absent; keep one literal sitemap list.
- **WR-G3-03** `web/src/layouts/PublicLayout.test.tsx:299-321`: `expectNoCookieBar()` passes even if the layout renders nothing and waits a fixed 750 ms. Fix: assert a landmark first, then `queryByRole`.
