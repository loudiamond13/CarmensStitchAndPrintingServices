<assumption_delta_decision>
The assumption-delta scan fired on the word "optional" ("sets no optional cookies"). That is the cookie category being removed, not a required field becoming optional. Primary noun: the daily page count (`DailyPageCount`, keyed by business day and page key), unchanged. Decision: `no-change`. Rationale: the phase removes the visitor identity (visitor id, visits) instead of generalizing it; nothing is added alongside it, so no promote or accepted debt applies.
</assumption_delta_decision>

<objective>
The rest of the server half of D-59 and D-53: the page view handler is cut down to the anonymous count, then the stores, keys and Domain helpers that only the visit half used are deleted, and the server stops being able to write a consent or visitor id cookie. The tables stay (D-56, D-61), so no migration is written. Review findings WR-G1-03 and WR-G2-03 (12-REVIEW-FIX.md) are resolved by this plan with plan 12.1-09.

Requirements this plan reduces: ANL-05 (no visitor id, sessions, referrer or device stored), ANL-06 (path and day only). The rewording is done by plan 12.1-17.

Purpose: one anonymous write route that can only add to a few daily counters.
Output: a smaller handler, context and request, regenerated API types, deleted stores and helpers, a longer reflection gate.
</objective>
