## Sampling Rate

- **After every task commit:** the quick command for the touched test file(s).
- **After every plan wave:** preflight, then `dotnet test Csps.slnx`, `dotnet format Csps.slnx --verify-no-changes --no-restore`, `npm --prefix web run verify` (delete `web/node_modules/.vitest-cache` first after file adds or removals), `npm --prefix tools/openapi-gen run check`.
- **Before `/gsd-verify-work`:** full suites green, `npm --prefix web run e2e` for the touched tags in all five projects, `npm --prefix web run lighthouse`.
- **Max feedback latency:** 60 seconds for quick runs.
