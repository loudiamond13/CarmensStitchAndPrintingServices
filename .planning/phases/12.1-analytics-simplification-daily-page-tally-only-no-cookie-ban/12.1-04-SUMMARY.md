# Phase 12.1 Plan 04: Saved Show Map tap Summary

**One tap on Show Map is now saved in the browser as `csps-maps` = `show`, so later visits load the Google map frame in the first render with no banner, no cookie and no consent store.**

## Performance

- **Duration:** about 32 min
- **Started:** 2026-11-18T18:55:00-06:00
- **Completed:** 2026-11-18T19:30:00-06:00
- **Tasks:** 2
- **Files modified:** 7 (2 created, 5 modified)

## Accomplishments

- `mapChoice.ts` holds the saved setting: `MAPS_KEY`, `readMapsShown`, `saveMapsShown`, `subscribeMapsShown`. Reads are true only for the exact value `show` and false on any throw. Writes are guarded and still tell listeners when storage refuses. The subscribe covers this page and the window `storage` event.
- `MapCard` reads the setting with `useSyncExternalStore(subscribeMapsShown, readMapsShown, () => false)`. The tap lives in state apart from the setting, so clearing the key in another tab unloads an automatic frame but not one the visitor tapped in this view. Focus moves into the frame only after the visitor's own tap.
- The consent store, `CONSENT_COPY`, the Always show maps button, the status line, the Cookie Settings line and two recipe classes are gone from the map card. The wording `The map loads from Google when you tap Show Map.` and the plain Directions link are unchanged (D-66). The CSP was not touched.
- `web/src/test/setup.ts` clears the key before every test.
