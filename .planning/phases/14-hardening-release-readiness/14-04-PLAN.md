# Plan 14-04: A CI-only mailbox tool lets the signed-in scan walk the real sign-in flow (14 D-36)

*Created: 2026-11-27T08:05:00-06:00 · Updated: 2026-11-27T08:05:00-06:00*

> MVP note: the ROADMAP Goal line for Phase 14 is not in user-story form, so no story was invented.

<objective>
Build `tools/Csps.CiMailbox`, a console tool that runs only in GitHub Actions against the CI SQL container's `CSPS_Zap` database. It reads the newest queued invite or sign-in code email for one recipient from the outbox, decrypts it with the app's own key ring, and prints just the token or the code, so a script can walk invite, set password, sign in and code exactly as a person does (14 D-36, D-04).

Purpose: a Production build has no Testing mail sink and no SMTP in CI, so the queued emails are the only way to finish the real flow without minting tokens or changing the app.
Output: the tool, its test project, solution wiring.
</objective>
