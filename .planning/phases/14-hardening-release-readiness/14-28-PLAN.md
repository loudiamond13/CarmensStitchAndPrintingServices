## Executor rules (owner, binding)

- Work only in the worktree or the follow-up branch the owner names; never merge or push; never touch the main checkout.
- The owner runs the passes; Claude never marks a step the owner did not report. In away mode, park Task 1 in the backlog with the record's path and the steps.
- A failure that needs a code fix: small and inside the approved design, fix it with a failing test first and ask the owner to re-check that step; otherwise bring it to the owner with a recommendation (or plan it with `/gsd-plan-phase 14 --gaps`).
- Shared machine: the owner starts the dev servers for the NVDA pass after the preflight (docs/development.md); Claude leaves no server or background shell running. Never read stdin.
- Writing: plain English; no name, email, phone or device id in the record (D-22); timestamps.
- Commits: `gitleaks protect --staged --no-banner`. Stage by path. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
