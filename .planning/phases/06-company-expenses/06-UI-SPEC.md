### Routes

| Route | Screen | Look source | Guard |
|-------|--------|-------------|-------|
| `/admin/expenses?q=&category=&from=&to=&page=&size=` | E1 Company Expenses | App. E.11 with § SPEC-DEVIATION items | Both roles (D-25) |

| `/admin/settings` | S1 Settings | SPEC-GAP: `.s-ph` + `.s-card` + `.s-rt` | Manager policy (D-14). An Admin is redirected to `/admin` by the route `loader`, as on `/admin/users`; the API answers 403 for category writes. |

Both new pages are lazy admin chunks and count toward no initial budget (admin initial JS stays ≤ 250 KB gz). The sidebar and tab bar mark **Company Expenses / Expenses** current on E1 and E4, and **Settings** current on S1 (no tab-bar item is current on S1, as on the Audit Log).

**URL params (WEB-10, allow-list parsers):**
- `q`: trimmed, capped at 100 (`searchParser`).
- `category`: one category id, validated by shape (the planner fixes GUID or integer to match the key type); an id the category list does not hold falls back to "All categories" with one `replace`.
- `from`, `to`: `parseAsBusinessDate`, read **only as a pair**. With neither, the D-23 default window applies (30 days before to 30 days after the business today, resolved on every visit, never stored). With one missing or invalid, or `from` after `to`, both are dropped with one `replace`.
- `page` ≥ 1 (a page past the last is replaced by the last); `size` ∈ {10, 20, 50, 100}, default 20.
- Defaults stay out of the URL. A filter, search or page-size change replaces the entry and resets the page to 1; a page change pushes. The search writes the URL with `debounce(300)` and the query key uses `useDebouncedValue(q, 300)`.

**Document titles:** "Company Expenses · CSPS Admin", "Deleted Expenses · CSPS Admin", "Settings · CSPS Admin".

**Order of blocks in E1 `main.s-body`:** page header, KPI row, toolbar with result bar, table with its caption. On phones (≤ 767) the KPI row is one column, the toolbar fields wrap two per row (App. C), the table becomes stacked cards, and the header actions take the full width (App. C `.s-ph-actions > * { flex: 1 }`).
