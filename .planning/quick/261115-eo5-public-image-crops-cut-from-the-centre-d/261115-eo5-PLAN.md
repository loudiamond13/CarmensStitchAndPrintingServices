<objective>
Owner ruling D-130 (owner, 2026-11-15, option A "all public website crops"): every public website fill crop cuts from the centre (Cloudinary `g_center`) instead of the smart crop (`g_auto`). The owner uploaded a wide promo poster as a product line main photo, and `g_auto` slid the 4:5 Home category card window onto the shirts, cutting off the logo and the phone number. The owner wants predictable centred crops on the public site.

Named sizes already in use are never edited (the setup command refuses to change a `different` size, and live photos use them). So this plan adds 15 new centre-cut named sizes, points the public slots at them, keeps the 15 old smart-crop names in the catalog so addresses already handed out keep working (the account count goes from 34 to 49), updates the tests, the web fixtures and the docs, and records D-130.

Purpose: the public site shows each photo's middle, the same way every time.
Output: 15 new named sizes in `ImageNamedSizes`, the public slots using them end to end, tests pinning them, owner setup docs, and the D-130 bullet.
</objective>
