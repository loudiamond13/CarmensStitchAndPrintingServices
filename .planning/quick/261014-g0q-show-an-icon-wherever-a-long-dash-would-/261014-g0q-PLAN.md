# 261014-g0q: Show an icon wherever a long dash would be a symbol

<objective>
Owner rule (2026-10-14, follow-up to 261014-ctx): "if you want to use em dash use icon." The client's one symbolic dash is the empty or missing value (CSPS-UI-SPEC.md §9.4 "Empty"), which 261014-ctx turned into a plain hyphen. Replace it with a shared `EmptyValue` component that draws the lucide `minus` icon (hidden from assistive technology) plus visually hidden "Not set". Formatters stop returning a dash string and return `null`, and each render site shows `<EmptyValue />` for it. Plain prose keeps ordinary punctuation (`Mon-Sat`, `9:00 AM - 6:00 PM`), so it is out of scope. Then record the refined OR-4 rule in both CLAUDE files and the Phase 4 UI-SPEC.

Purpose: OR-4 compliance without a hyphen stand-in, accessible (WCAG 1.1.1, A11Y-01), with one implementation every list and card reuses (WEB-06).
Output: `EmptyValue` in `@/components`, the `minus` icon, null-returning date formatters, updated ResponsiveTable and OrderCard, tests, and the amended rule text.
