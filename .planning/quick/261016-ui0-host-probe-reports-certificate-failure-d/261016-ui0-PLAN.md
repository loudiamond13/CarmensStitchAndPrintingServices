<interfaces>
The current probe check (tools/Csps.HostProbe/HostFacts.cs) does this: RSA.Create(2048), then CertificateRequest("CN=Csps.HostProbe", SHA256, Pkcs1).CreateSelfSigned(now-5min, now+1day), then a random hex password, then certificate.Export(X509ContentType.Pkcs12, password), then X509CertificateLoader.LoadPkcs12(pfx, password, EphemeralKeySet), then OAEP with SHA-256 encrypt/decrypt. It catches CryptographicException or PlatformNotSupportedException and returns only the type name.

Production certificate (docs/operations/data-protection-rotation.md): Windows PowerShell 5.1. RSA::Create(3072), the same CertificateRequest shape, then $certificate.Export('Pfx', $password). CSPS loads it with X509CertificateLoader.LoadPkcs12(pfx, password, EphemeralKeySet).

Data Protection's certificate encryptor uses EncryptedXml with an RSA-1_5 key wrap, so its key operation is RSA PKCS#1 v1.5 (RSAEncryptionPadding.Pkcs1).

API confirmed in the installed ref pack (Microsoft.NETCore.App.Ref 10.0.13): X509Certificate2.ExportPkcs12(Pkcs12ExportPbeParameters, string) and Pkcs12ExportPbeParameters { Default, Pkcs12TripleDesSha1, Pbes2Aes256Sha256 }.

The probe answers with Results.Json, which uses the ASP.NET Core web JSON defaults (camelCase). In tests, JsonSerializerOptions.Web gives the same names.
