### Notes on how it was built

- **Date field widths:** the plan said to check the compiled CSS order. I read it: a date width (`flex-[0_1_232px]`) lands after the plain toolbar width, so it wins without the important modifier. On phones `basis-full` lands after the plain phone width. `expenses.recipe.node.test.ts` pins this order. The plan's `flex-[1_1_100%]` would have lost to the plain width, so the phone rule is `basis-full`.
- **Search box height:** `h-10.5` compiles under the class gate (spacing is 4px, so 42px).
