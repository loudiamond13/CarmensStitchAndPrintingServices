## Decisions made under delegation

- The Group select is page state (`useState`), not a URL parameter: it filters nothing and sends nothing. `useAuditListParams` is untouched.
- The group shown is derived in render (no effect). If an action in the URL is outside the picked group, the select shows the action's group, so the Action select never lacks its value.
- Picking a group that does not hold the chosen action calls `setFilter('action', null)` (a replace that resets the page). Picking a group when no action is set causes no URL write. "All groups" keeps the action. Clear Filters resets the group.
- Stated lines (added or removed entries) use the same "<Field> changed" fallback, since D-81 names no exception.
- Person lines read 'Payer changed', 'Receiver changed', 'Refunder changed' ("Paid by changed" is not plain English).
- The fallback sentence is built only from the fixed label, never from the stored values (T-87p-01). A field the viewer does not know is still left out (null).
