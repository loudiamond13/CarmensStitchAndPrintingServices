<objective>
Make the one merge command set the squash commit message itself, and make the merge gate refuse a message that would carry a GitHub skip marker.

Purpose: on 2026-10-16 the squash merge of PR #1 (fb9b20c on main) used GitHub's default message, the full concatenated commit log, and one old commit in it quoted a skip marker. GitHub then ran no push workflow on main (CI, CodeQL, Hygiene), so no `csps-package-<sha>` was uploaded and plan 03-17's deploy is blocked until a clean push to main runs CI. Composing the message from the PR title (OPS-01, D-08) closes that hole for every future merge.

Output: `squashMessage` and `skipMarkersIn` in `web/scripts/merge-gate.mjs` with new refusals and output lines, tests in `web/scripts/merge-gate.test.ts` (RED commit, then GREEN), the script change in `tools/scripts/Merge-PullRequest.ps1`, and a short update to `docs/operations/branch-rules.md`.
</objective>
