# How to: put the staff app on a phone or computer

*Created: 2026-11-27T21:12:00-06:00 · Updated: 2026-11-27T21:12:00-06:00*

Staff can install the admin area as an app named **CSPS Admin**. It then opens in its own window, with its own icon, like any other app (PERF-06, 14 D-28). The installed app is the same website. It is only for staff, and it works only under the admin address.

There is **no install button** inside CSPS. The browser offers the install itself, so the steps below use the browser's own menu. The owner decided this (14 D-28). On an iPhone a page cannot show such a button at all.

Install from the staff sign-in address, the site address followed by `/admin`. The public pages do not offer it.

## Chrome or Edge (Android, Windows, Mac)

1. Open the staff sign-in address in Chrome or Edge.
2. Open the browser menu (the three dots).
3. Choose **Install app**. In Edge the menu item is under **Apps**, and it may read "Install this site as an app". The exact words change a little between browser versions.
4. Confirm **Install**. The app opens in its own window and gets an icon on the home screen or the Start menu.

On a computer, Chrome and Edge may also show a small install icon at the right end of the address bar. It does the same thing.

## iPhone (Safari)

The install works only in Safari on an iPhone, not in other browsers.

1. Open the staff sign-in address in Safari.
2. Tap the **Share** button (the square with an arrow).
3. Scroll down and tap **Add to Home Screen**.
4. Keep the name **CSPS Admin** and tap **Add**.

**The iPhone app asks you to sign in again.** The installed app keeps its own sign-in, apart from Safari's. So the first time you open it, it asks for your password and the emailed code again. This is how iOS works. It is not a defect, and nothing is wrong with your account.

## When there is no signal

The installed app shows a plain "You're offline" page. Orders and payments need a connection, and nothing is stored on the device. Press **Try Again** when you have signal.

## Removing the app

Remove it like any other app: press and hold the icon on a phone, or use the app's menu in Chrome or Edge on a computer. Removing it does not delete anything from CSPS.

## If the install choice does not show

- Check that you opened the staff sign-in address, not a public page.
- On an iPhone, check that you are in Safari.
- Tell the owner if it still does not show. Staff can keep using the site in the browser as before.
